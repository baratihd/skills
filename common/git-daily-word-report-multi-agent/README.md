# Multi-agent distribution: git-daily-word-report

Skill source: `git-daily-word-report/` (self-contained, suitable for a central skills repository).

Install: `./install-skill.sh /absolute/path/to/project`

Supported skill discovery paths:
- Codex `.agents/skills/git-daily-word-report/`
- OpenCode `.agents/skills/` or `.opencode/skills/`
- Claude Code `.claude/skills/`

Installer never overwrites an installed skill. Back up and remove an old copy before updating. The canonical installed source is `.agents/skills/`; the other two paths are symbolic links.
