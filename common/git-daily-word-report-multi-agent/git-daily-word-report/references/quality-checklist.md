# Daily Git Report Checklist

- [ ] Date window and timezone correct, with no older activity presented as today's.
- [ ] Git author identity checked; author-date and commit-date distortions considered.
- [ ] Local branches considered; duplicate/cherry-picked work not counted twice.
- [ ] Each substantive item supported by diff, relevant file, or commit.
- [ ] Committed work separated from present but undated worktree changes.
- [ ] Technical edits translated to realistic business or engineering outcomes.
- [ ] No unsupported claim of completed ticket, validated fix, review, deployment, or passing tests.
- [ ] Blockers and next steps distinguish evidence from proposals.
- [ ] No secrets, tokens, customer data, or confidential payloads exposed.
- [ ] Default output in Persian and digestible by a manager / Scrum Master.
- [ ] Read-only Git workflow; no implicit write to repo or remote.
