# گزارش تغییرات سناریوهای تست

| مشخصه | مقدار |
|---|---|
| شاخه مبدأ | `SOURCE_REF` (`SOURCE_SHA`) |
| شاخه مقصد / مبنای مقایسه | `TARGET_REF` (`TARGET_SHA`) |
| روش مقایسه | `merge-base...source` |
| تاریخ تهیه | `DATE` |
| دامنه | `SCOPE` |
| اجرای تست | اجرا نشده / با ذکر دستور و نتیجه |

## تست‌های ایجادشده

### TS-NEW-001 — عنوان فارسی سناریو

- **قابلیت:** توضیح قابلیت
- **نوع تست:** Unit / Integration / API / E2E / Smoke / Security / Performance / Migration / Property
- **مرجع تست:** `tests/example/test_file.py::TestFeature::test_action`
- **تغییر انجام‌شده:** افزوده شدن این سناریوی تست و محدوده بررسی آن
- **پیش‌شرط (Given):** داده‌ها و وضعیت اولیه
- **اقدام (When):** عملکرد مورد بررسی
- **انتظار (Then):** نتیجه‌ای که Assertهای واقعی تست بررسی می‌کنند
- **Fixture / Mock:** نام و نقش وابستگی‌های واقعی
- **ورودی و حالت مرزی:** در صورت وجود
- **انتظار از کد:** با تفکیک انتظار در Assert و قرارداد مستندشده
- **شواهد:** مسیر تست / مسیر کد / مسیر مستندات
- **وضعیت تأیید:** براساس کد / اجراشده / نیازمند تأیید
